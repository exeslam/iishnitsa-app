# Claude Code за вечер

Ставим Claude Code, подключаем подписку и делаем первый проект. Программировать не нужно, всё пишешь словами.

## 🧰 Что понадобится

1. **Подписка Claude Pro** от $20 в месяц. На бесплатном тарифе Claude Code нет.
2. **Компьютер** на macOS 13 и новее или Windows 10 и новее, от 4 ГБ памяти.
3. **Карта** из страны, где работает Claude. Казахстан в списке есть, Россия нет.
4. **Час свободного времени.**

## ⏱ Установка по шагам

**0-5 минута. Подписка**
Зайди на claude.com/pricing и оформи Pro. Если платёж не проходит, проверь, что страна карты совпадает с адресом и что карта не виртуальная.

**5-10 минута. Установка**
Открой Терминал на Mac или PowerShell на Windows и вставь команду из блока ниже. Node.js ставить не нужно.

**10-15 минута. Вход**
Напиши в терминале claude и нажми Enter. Откроется браузер, войди в свой аккаунт Claude.

**15-20 минута. Проверка**
Команда claude doctor покажет, всё ли в порядке. Если что-то не так, она подскажет, что именно.

**20-60 минута. Первый проект**
Создай пустую папку, открой её в терминале, запусти claude и попроси сделать сайт-визитку. Промпт ниже.

## 💻 Команды установки

**Mac**
```
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows, PowerShell**
```
irm https://claude.ai/install.ps1 | iex
```

**Проверка**
```
claude doctor
```

## 💬 Первые запросы

**1. Сайт-визитка**
```
Сделай мне сайт-визитку в одном файле index.html. Меня зовут [имя], я [чем занимаешься]. Нужны блоки: кто я, чем могу помочь, 3 примера работ, кнопка написать в Telegram [ссылка]. Стиль чистый, светлый, крупный текст, хорошо смотрится на телефоне.
```

**2. Правила проекта**
```
/init
```

**3. Сначала план**
```
/plan Сделай страницу с ценами на мои услуги: [услуги и цены]. Сначала покажи план, ничего не меняй, пока я не соглашусь.
```

## 🧠 Полезные команды

- **/init** создаёт файл CLAUDE.md, где Claude запоминает правила проекта
- **/plan** сначала план, потом действия
- **Shift+Tab** переключает режимы: с подтверждением, авто, план
- **/clear** начать новый диалог
- **Esc** остановить Claude, если он пошёл не туда

## 🚫 Частые ошибки

- **Бесплатный тариф.** В нём нет Claude Code, нужен минимум Pro.
- **Всё в одном длинном чате.** Когда контекст забит, Claude теряет начало. Для новой задачи делай /clear.
- **Сразу делать, без плана.** Для больших задач сначала /plan, так меньше переделок.
