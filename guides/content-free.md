# Всё бесплатное для контента

Шрифты, музыка, фото и видео, за которые не прилетит страйк. Проверено по официальным сайтам 25.09.2026.

## 🔤 Шрифты с кириллицей

1. **Inter** нейтральный гротеск для текста на слайдах.
2. **Onest** современный, хорошо смотрится на русском.
3. **Manrope** для чистых заголовков.
4. **Unbounded** широкий и заметный, для обложек.

Все четыре на Google Fonts под лицензией OFL, их можно использовать в коммерции.

## 🎵 Музыка для рилсов

- **Meta Sound Collection** самый безопасный вариант для бизнес-аккаунта, разрешена для коммерции и рекламы.
- **Обычная музыка Instagram** только для личного некоммерческого использования, у бизнес-аккаунтов её могут закрыть.
- **Pixabay Music** можно в соцсетях, но часть треков Instagram может заглушить. Тогда оспариваешь с лицензией Pixabay.

## 📷 Фото и видео

- **Unsplash, Pexels, Pixabay** бесплатные фото, подпись автора не обязательна.
- **Pexels и Pixabay** ещё и бесплатные видео для фона рилса.

## 🚫 Чего не делать

- **Музыку из YouTube Audio Library в Instagram.** Её правила про YouTube, в рилсе трек могут заглушить.
- **Canva из России без VPN.** Сервис закрыт для России с 2022 года, в Казахстане работает.
