# Мультиагентная система: команда нейросетей в Claude Code

Привет, это Умар из канала ИИшница 🍳

Обещал в рилсе, держи. Тут что такое мультиагентная система, когда она реально нужна и как собрать свою команду в Claude Code за 10 минут.

## 🧠 Что это простыми словами

Обычная нейросеть работает как один сотрудник: берёт задачу и делает всё сама, по очереди.

Мультиагентная система работает как отдел. Главный агент получает задачу, делит её на части и раздаёт помощникам. Каждый помощник, их называют субагентами, делает свой кусок со своим чистым контекстом. Потом главный собирает результат.

В Anthropic проверили это на исследовательских задачах. Команда из главной модели Opus и помощников Sonnet справилась на 90% лучше, чем одна Opus в одиночку.

## ⚖️ Когда нужна, а когда нет

**Нужна**, когда задачу можно разрезать на независимые части:
- исследование рынка или конкурентов по нескольким направлениям сразу;
- собрать и сравнить информацию из разных источников;
- большой объём текста, который не влезает в одну переписку.

**Не нужна** для простых задач. Написать пост, ответить клиенту, поправить текст одна нейросеть сделает быстрее и дешевле.

**Цена.** По данным Anthropic, мультиагентная система тратит примерно в 15 раз больше токенов, чем обычный чат. На подписке это значит, что лимит кончится быстрее. Включай команду, когда задача того стоит.

## 🛠 Как собрать команду в Claude Code

Субагент это обычный текстовый файл с инструкцией. Лежит в папке `.claude/agents/` твоего проекта или в `~/.claude/agents/`, если он нужен во всех проектах.

**Способ 1. Попроси Claude Code**
<pre>Создай в .claude/agents/ трёх субагентов:
researcher: ищет факты и источники по теме, отдаёт список с ссылками;
writer: по найденным фактам пишет понятный текст для соцсетей;
checker: проверяет текст, находит неточности и утверждения без источника.
Пусть researcher и checker работают на модели sonnet.</pre>

**Способ 2. Напиши файл сам**
Например, `.claude/agents/checker.md`:
<pre>---
name: checker
description: Проверяет готовый текст на ошибки и утверждения без источника. Use proactively после написания текста.
tools: Read, WebSearch
model: sonnet
---

Ты редактор-фактчекер. Найди в тексте цифры и факты без источника,
логические дыры и места, которые звучат как нейросеть. Выдай список правок.</pre>

Обязательных поля два: `name` и `description`. По описанию Claude решает, когда звать этого помощника.

## 🚀 Как запустить

Просто напиши задачу и назови помощников:
<pre>Используй субагентов. researcher пусть параллельно изучит 3 темы: [тема 1], [тема 2], [тема 3]. Потом writer соберёт из этого пост, а checker проверит его.</pre>

Можно вызвать конкретного помощника напрямую: напиши `@agent-checker` и задачу.

## 💡 Три правила, чтобы команда работала

1. **Каждому помощнику одна задача и формат ответа.** "Найди 5 конкурентов и дай таблицу" лучше, чем "поищи что-нибудь".
2. **Размер команды по задаче.** Простой вопрос: один агент. Большое исследование: несколько помощников параллельно.
3. **Последнее слово за проверкой.** Помощник-проверяющий экономит больше всего нервов.

Если застрял, пиши в комментариях под постом в канале, разберёмся 🙌
