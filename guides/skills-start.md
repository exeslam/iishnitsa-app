# Скиллы за 10 минут

Скилл это инструкция, которая учит Claude делать задачу по-твоему. Один раз написал, дальше Claude делает так всегда.

## 🧩 Что это такое

1. **Скилл это папка с файлом SKILL.md.** Внутри короткое описание и инструкция.
2. **Claude сам понимает, когда он нужен.** Пока скилл не нужен, Claude видит только описание, поэтому скиллов можно поставить много.
3. **Можно вызвать руками** командой через слэш, например /название-скилла.

## 📂 Где лежат скиллы

- **Для всех проектов:** ~/.claude/skills/название/SKILL.md
- **Только для одного проекта:** .claude/skills/название/SKILL.md в папке проекта

## ⏱ Первый скилл по шагам

**0-2 минута. Открой каталог**
В Claude Code набери /plugin, откроется каталог плагинов. В плагинах лежат готовые скиллы.

**2-4 минута. Поставь frontend-design**
Он учит Claude делать сайты с характером, а не шаблон как у всех. Команда ниже.

**4-10 минута. Сделай свой**
Попроси Claude создать скилл под твою задачу. Промпт ниже, подставь своё.

## 💻 Команды

**Установить скилл дизайна**
```
/plugin install frontend-design@claude-plugins-official
```

**Создать свой скилл**
```
Создай скилл [название] в папке ~/.claude/skills. Он нужен, чтобы [что делать]. Правила: [твои правила, например тон, длина, формат]. Пример хорошего результата: [пример]. Опиши в description, когда его включать.
```

## 📝 Шаблон SKILL.md

```
---
name: [название-латиницей]
description: [когда включать этот скилл, одним предложением]
---

Что делать:
1. [шаг]
2. [шаг]

Правила:
- [правило]
```

## 🚫 Частые ошибки

- **Размытое описание.** Если description общее, Claude не поймёт, когда включать скилл. Пиши конкретно: для чего и в каких задачах.
- **Скилл на всё сразу.** Один скилл, одна задача. Так они не мешают друг другу.
