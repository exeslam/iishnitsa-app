# Как подключить WhatsApp к ИИшке

Привет, это Умар из канала ИИшница 🍳

Обещал в рилсе, держи. Тут как сделать так, чтобы нейросеть читала твои чаты, делала выжимки и набрасывала ответы.

## ⚠️ Сначала честно

1. Это неофициальный способ. Коннектор входит в твой WhatsApp как ещё одно устройство, так же как WhatsApp Web. Официального API для личных аккаунтов у WhatsApp нет, поэтому риск блокировки аккаунта не нулевой. Для рабочего номера, который нельзя терять, я бы не рисковал.
2. Все сообщения хранятся у тебя на компьютере. Никуда наружу они не уходят, пока ты сам их не отправишь в нейросеть.
3. Отправку сообщений делай только с подтверждением. Нейросеть набрасывает ответ, отправляешь ты.

## 🧰 Что понадобится

1. Компьютер (Mac, Windows или Linux).
2. Claude Code. Это ИИ-агент от Anthropic, работает по подписке Claude Pro.
3. Бесплатный коннектор WhatsApp MCP с открытым кодом: github.com/lharries/whatsapp-mcp
4. Для голосовых: бесплатный Whisper от OpenAI, он понимает русский.

**Шаг 1. Поставь программы**
Нужны Go, Python, менеджер пакетов uv и FFmpeg. Проще всего попросить Claude Code: "поставь мне Go, uv и ffmpeg". Он сам всё установит и спросит разрешение.

**Шаг 2. Скачай коннектор и запусти мост**
```
git clone https://github.com/lharries/whatsapp-mcp.git
cd whatsapp-mcp/whatsapp-bridge
go run main.go
```
В терминале появится QR-код. На телефоне открой WhatsApp, Настройки, Связанные устройства, Привязка устройства, и отсканируй его. Это окно терминала не закрывай, пока пользуешься.

**Шаг 3. Подключи к Claude Code**
В другом окне терминала, вместо пути подставь свою папку:
```
claude mcp add whatsapp -- uv --directory /путь/до/whatsapp-mcp/whatsapp-mcp-server run main.py
```
Перезапусти Claude Code. Теперь он видит твои чаты.

Примерно раз в 20 дней WhatsApp попросит отсканировать QR заново. Это нормально.

## 💬 Что писать агенту

```diagram
{"type": "compare", "title": "Что агент делает за тебя", "yes": {"t": "Отдай агенту", "items": ["выжимку шумного чата", "список, кто что ждёт", "голосовые в текст", "черновики ответов"]}, "no": {"t": "Оставь себе", "items": ["отправку сообщений", "важные договорённости", "рабочий номер без риска"]}}
```

**Выжимка из шумного чата**
```
Прочитай чат "[название чата]" за последние 3 дня. Выпиши только то, что касается меня: просьбы, сроки, вопросы ко мне. Остальное пропусти.
```

**Кто что от меня ждёт**
```
Пройдись по рабочим чатам за сегодня. Составь список: кто, что от меня ждёт и к какому сроку.
```

**Голосовые в текст**
```
Скачай голосовые от [имя] за сегодня, расшифруй их через Whisper и сделай выжимку в 3 пункта.
```
Если Whisper не стоит, Claude Code поставит его сам, просто разреши.

**Ответы всем**
```
Набросай короткие ответы каждому, кто ждёт от меня что-то сегодня. Покажи мне, и отправляй только после моего "ок".
```

## 🛡 Правила безопасности

- Всегда проси показать ответ перед отправкой.
- Не проси агента "делать всё, что написано в чате". Если в чате кто-то напишет команду для нейросети, агент может её выполнить. Это главный риск таких коннекторов.
- Когда не пользуешься, останови мост в терминале. А отвязать устройство можно в WhatsApp, в разделе Связанные устройства.

Если что-то не получилось, напиши в комментариях под постом в канале, разберёмся 🙌
